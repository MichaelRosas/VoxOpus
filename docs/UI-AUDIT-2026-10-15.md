## Earcons

The user supplied earcon1.flac and earcon2.flac. Converted losslessly to 16-bit stereo PCM WAV at 48kHz for browser compatibility; both are about 0.857 seconds. Stored under frontend/public/audio. Earcon 1 maps to `onaudiostart`; earcon 2 maps to `onaudioend`, with an `onend` fallback and per-session duplicate guard. No start cue for a permission failure. No cue looping during speech. AudioContext resumes from the Start button gesture; assets preload and decode ahead of time. Stop interrupts any unfinished start cue. Cleanup closes audio resources and removes handlers. Audio failure must not block the existing speech workflow; visible status remains available. Extremely early interaction before decoding, blocked audio, muted output, or asset loading failure can prevent audible cues.
