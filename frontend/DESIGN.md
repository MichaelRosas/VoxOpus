# VoxOpus interface

Student task workspace: calm, focused, approachable. Compact product identity, manual task input, and a wider task review area. Mobile stacks input above the list. No marketing hero, decorative animation, cards, gradients, or voice functionality placeholders.

Primary #245642; accent #91452e for destructive controls and focus; text #24352f; secondary #52635b; background #f4f6f5; fields #ffffff; dividers #cbd4cf. Body 16px Avenir Next/Segoe UI; product name 32px upright Palatino; section headings 22px. System-installed fonts avoid an external font dependency.

Borderless grouped scheduling fields, 48px inputs, at least 44px buttons, 6px control corners, divided task rows. Explicit labels and visible keyboard focus. CSS comments explain layout and control behavior. See ../docs/UI-AUDIT.md for evidence, original findings, and verification limits.
